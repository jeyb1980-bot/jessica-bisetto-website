# Startpaket für Claude Code

Dieses Paket hilft dir, aus dem fertigen Design eine echte, veröffentlichte Website zu machen — mit Claude Code als deinem Entwickler.

---

## Schritt 1 — Projekt herunterladen

Lade dieses gesamte Projekt als ZIP herunter (Download-Karte im Chat) und entpacke es in einen Ordner auf deinem Computer, z. B. `jessica-bisetto-website`.

## Schritt 2 — Claude Code installieren

Falls noch nicht geschehen: Installiere Claude Code nach der offiziellen Anleitung von Anthropic. Du brauchst dafür ein Claude-Konto.

## Schritt 3 — Claude Code im Projektordner öffnen

Öffne ein Terminal **in dem entpackten Ordner** und starte Claude Code dort. Claude Code liest automatisch die Datei `CLAUDE.md` — darin steht das komplette Briefing.

## Schritt 4 — Diese Erst-Anweisung eingeben

Kopiere den folgenden Text und füge ihn als erste Nachricht in Claude Code ein:

---

> Lies zuerst `CLAUDE.md` und `skills/jessi/SKILL.md` vollständig. Schau dir dann den vorhandenen Prototyp in `ui_kits/` und das Design-System in `colors_and_type.css` an.
>
> Baue daraus eine produktionsreife Website mit **Astro**. Übernimm Design, Komponenten, Farben, Schriften und Inhalte **1:1** aus dem Prototyp. **Self-hoste** die Schriften (kein Google-CDN).
>
> Richte ein Headless-CMS (Sanity oder Storyblok, EU/kostenlos) für **Kurse, Blog, Kundenstimmen und Referenzen** ein, damit ich Inhalte ohne Code pflegen kann. Mach das Kontakt- und Erstgespräch-Formular und den Newsletter **funktionsfähig** (DSGVO-konform, Double-Opt-in). Füge Cookie-Banner, Impressum, Datenschutz und AGB als Seiten hinzu.
>
> Ich bin **keine Entwicklerin** — erkläre mir alles in einfachen Worten und arbeite in überschaubaren Etappen. Halte dich bei allen Texten strikt an `skills/jessi/SKILL.md`. Erfinde keine Namen, Referenzen, Preise oder Methoden — frag mich, wenn etwas fehlt.
>
> Wenn die Seite steht: richte das Hosting bei **Cloudflare Pages oder Netlify** ein, verbinde es über GitHub, und führe mich Schritt für Schritt durch die Veröffentlichung und das Verbinden meiner Domain `jessica-bisetto.de`. Warne mich rechtzeitig, was ich beachten muss, bevor ich mein Wix-Abo kündige (z. B. meine E-Mail-Adresse).
>
> Fang an, indem du mir deinen geplanten Ablauf in einfachen Worten zusammenfasst und mir Rückfragen stellst, bevor du baust.

---

## Schritt 5 — Mitgehen, nicht alles auf einmal

Claude Code wird dir Rückfragen stellen und in Etappen arbeiten. Antworte in deinen Worten — du musst nichts Technisches können. Bei jeder Etappe kannst du dir das Ergebnis zeigen lassen.

## Worauf du achten solltest

- **E-Mail nicht vergessen:** Falls `kontakt@jessica-bisetto.de` über Wix läuft, kläre den Umzug, bevor du Wix kündigst.
- **Rechtliches prüfen lassen:** Impressum, Datenschutz und AGB sollte ein Anwalt oder ein Dienst wie eRecht24 final absegnen.
- **Wix erst kündigen, wenn die neue Seite live und getestet ist.** Kein Risiko eingehen.

## Wenn du nicht weiterkommst

Komm jederzeit hierher zurück — ich kann dir Texte schreiben, Designfragen klären, einzelne Bausteine anpassen oder dir erklären, was Claude Code gerade meint.
